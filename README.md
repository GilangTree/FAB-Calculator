# 📊 Calculator FAB
> Floor Area Bersih — Kalkulator Shift Kerja

![PWA Ready](https://img.shields.io/badge/PWA-Ready-green?style=flat-square)
![Platform](https://img.shields.io/badge/platform-Android%20%7C%20iOS%20%7C%20Web-blue?style=flat-square)
![Offline](https://img.shields.io/badge/offline-supported-orange?style=flat-square)

Aplikasi kalkulator waktu kerja bersih (FAB) untuk operator shift pagi dan malam.
Tersedia sebagai PWA — bisa diinstall di Android & iPhone!

## ✨ Fitur
- ⏰ Hitung FAB otomatis (Morning 9j45m / Night 9j50m / Jumat 8j00m)
- 📷 Scan tiket izin keluar via OCR
- ⏱ Timer countdown notifikasi ticket aktif
- 🎨 7 tema warna (Default, Ocean, Sunset, Forest, Galaxy, Rose Gold, Midnight)
- 📊 Rekap lengkap + Export XLSX/CSV/Print
- 💾 Backup & Restore data JSON
- 📱 PWA — install di Android & iPhone
- 🔔 Push notification pengingat waktu kembali
- 📶 Offline mode (Service Worker)

## 🚀 Deploy GitHub Pages
1. Upload semua file ke repository
2. Settings → Pages → Source: main branch
3. Buka: `https://USERNAME.github.io/REPO-NAME`
4. Di HP: Add to Home Screen → Install!

## 📱 Cara Install di HP
**Android:** Chrome menu → "Tambahkan ke layar utama"
**iPhone:** Safari → Share → "Tambahkan ke Layar Utama"

## 📊 Rumus FAB
```
FAB = Durasi Kerja − Total CRout
Sholat/Kantin = Jam Kembali − 30 menit
Toilet/Klinik = Jam Kembali − 15 menit
```
